# Jack and Jill Trivia Quiz

## Overview

Jack and Jill Trivia Quiz is an interactive quiz application designed to provide a simple and engaging knowledge-based experience.

The project allows users to answer multiple-choice questions, receive feedback, track their score, and complete a structured trivia session through an easy-to-use interface.

---

## Key Features

- Multiple-choice trivia questions
- Score tracking
- Immediate user feedback
- Simple and organized interface
- Structured quiz flow
- End-of-quiz results
- Easy-to-update question content

---

## Project Purpose

This project was created to practice core programming concepts such as:

- Variables
- Conditional logic
- User input
- Score calculation
- Program flow
- Data organization
- Interface design

It also demonstrates how a small application can combine logic and user interaction into a complete working project.

---

## How to Run

1. Download or clone the project.
2. Open the project files in the appropriate development environment.
3. Run the main application file.
4. Start the quiz and answer each question.
5. Review the final score when the quiz is complete.
